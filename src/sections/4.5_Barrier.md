## Barrier synchronization

### Zadatak

Proces je pokrenuo $N$ niti koje treba da zajednički odrade neki posao `work1()`, i treba da pređu na posao `work2()` tek kada svih $N$ niti završe posao `work1()`. Slično, potrebno je da svih $N$ završe posao `work2()` pre nego što se pređe nazad na posao `work1()`. Poslovi se moraju obavljati sa ekskluzivnim pravom pristupa. Implementirati ovakvo ponašanje niti pomoću monitora.

Ekskluzivno pravo pristupa obezbeđuje monitor `CriticalSection` iz prethodnog zadatka, a barijeru monitor `Barrier`. Kod `Signal-and-Continue` discipline, poslednja nit koja stigne do barijere budi sve ostale niti pozivom `signalAll()`. Kod `Signal-and-Wait` i `Signal-and-Urgent-Wait` discipline operacija `signalAll()` ne postoji, pa poslednja nit budi jednu nit, ta nit budi sledeću, i tako redom.

**Rešenje sa `Signal-and-Continue` disciplinom**

```cpp
#include <thread.h>
#include <monitor.h>
#define N 5

class CriticalSection : SC_Monitor {
    bool locked = false;
    cond delay;
public:
    CriticalSection() : delay(this) {

    }
    void enter_section() {
        monitor {
            while (locked) 
                delay.wait();
            locked = true;
        }
    }

    void exit_section() {
        monitor {
            locked = false;
            delay.signal();
        }
    }

} cs;

class Barrier : SC_Monitor {
    int count = 0;
    cond barrier;
public:
    Barrier() : barrier(this) {
        // empty
    }
    void wait_barrier() {
        monitor {
            count += 1;
            if (count == N) {
                count = 0;
                barrier.signalAll();
            } else {
                barrier.wait();
            }
        }
    }
} bar1, bar2;

void a(int id) {
    while (true) {
        cs.enter_section();
        work1();
        cs.exit_section();
        bar1.wait_barrier();

        cs.enter_section();
        work2();
        cs.exit_section();
        bar2.wait_barrier();
    }
}
int main() {
    Thread ta[N];
    for (int i = 0; i < N; i++) 
        ta[i] = createThread(a, i);
    for (int i = 0; i < N; i++) 
        join(ta[i]);
    return 0;
}
```
