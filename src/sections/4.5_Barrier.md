## Barrier synchronization

### Zadatak

Proces je pokrenuo $N$ niti koje treba da zajednički odrade neki posao `work1()`, i treba pređu na posao `work2()` tek kada svih $N$ niti završe posao `work1()`. Slično, potrebno je da svih $N$ završe posao `work2()` pre nego što se pređe nazad na posao `work1()`. Poslovi se moraju obavljati sa ekskluzivnim pravom pristupa. Implementirati ovakvo ponašanje niti pomoću monitora.

**Rešenje sa `Signal-and-Wait` disciplinom**

```cpp
#include <thread.h>
#include <stdlib.h>
#include <monitor.h>
#define N 5
class CriticalSection;
class CS : public CriticalSection {
    ...
} cs;

class Barrier : SW_Monitor {
    int count = 0;
    cond barrier;
public:
    Barrier() : barrier(this) {
        // empty
    }
    void wait_barrier() {
        monitor {
            count += 1;
            if (count == N) {
                count = 0;
                barrier.signal();
            } else {
                barrier.wait();
                barrier.signal();
            }
        }
    }
} bar1, bar2;

void a(int id) {
    while (true) {
        cs.start_section();
        work1();
        cs.end_section();
        bar1.wait_barrier();

        cs.start_section();
        work2();
        cs.end_section();
        bar2.wait_barrier();
    }
}
int main() {
    Thread ta[N];
    for (int i = 0; i < N; i++) 
        ta[i] = createThread(a, i);
    for (int i = 0; i < N; i++) 
        join(ta[i]);
    return 0;
}
```
