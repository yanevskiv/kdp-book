## Shortest job next

### Zadatak

Proces je pokrenuo $N$ niti koje treba da pristupe kritičnoj sekciji po prioritetnom redosledu. Naime, ukoliko postoje više niti koje istovremeno žele da uđu u kritičnu sekciju, prva ulazi ona koja ima najmanje posla. Implementirati ovakvo ponašanje niti pomoću monitora.

Kod `Signal-and-Continue` discipline, signalizirana nit čeka u redu za ulazak u monitor, pa bi nit koja tek stiže mogla da uđe u kritičnu sekciju pre nje ukoliko bi `locked` bio postavljen na `false`. Zato nit koja izlazi iz kritične sekcije ostavlja `locked` na `true` kada budi neku nit, i time joj direktno predaje kritičnu sekciju. Kod `Signal-and-Wait` i `Signal-and-Urgent-Wait` discipline signalizirana nit odmah ulazi u monitor, pa nit koja izlazi može da postavi `locked` na `false` pre poziva `signal()`.

**Rešenje sa `Signal-and-Continue` disciplinom**

```cpp
#include <thread.h>
#include <stdlib.h>
#include <monitor.h>
#define N 5

class SJN : SC_Monitor {
    bool locked = false;
    cond delay;
public:
    SJN() : delay(this) {
        // empty
    }
    void enter_section(int prio) {
        monitor {
            if (locked)
                delay.wait(prio);
            locked = true;
        }
    }
    void exit_section() {
        monitor {
            if (delay.queue())
                delay.signal();
            else
                locked = false;
        }
    }
} sjn;

void a(int id) {
    int prio = rand() % 1000; // nasumicni prioritet
    while (true) {
        sjn.enter_section(prio);
        work();
        sjn.exit_section();
    }
}

int main() {
    Thread ta[N];
    for (int i = 0; i < N; i++) 
        ta[i] = createThread(a, i);
    for (int i = 0; i < N; i++) 
        join(ta[i]);
    return 0;
}
```
