## Sleeping barber

### Zadatak

Proces je pokrenuo jednu nit koja simulira ponašanje uspavanog berberina i $N$ niti koje simuliraju ponašanje mušterija koje dolaze kod berberina da se šišaju. Berberin spava dok mu ne dođe mušterija u berbernicu. Mušterija kada dođe u berbernicu treba da probudi berberina i sedne u red čekanja dok je berberin ne pozove na šišanje. Kada berberin završi sa šišanjem mušterije, mušterija plaća berberinu i odlazi. Ukoliko u berbernici nema mesta za sedenje, mušterija odlazi i vraća se nakon nekog vremena. Pomoću monitora, implementirati funkcije `void barber()` i `void customer(int id)` koje oponašaju berberina i mušterije respektivno.

Kod `Signal-and-Wait` i `Signal-and-Urgent-Wait` discipline, mušterija koja signalizira berberina odmah mu predaje kontekst, pa berberin može da pozove mušteriju na šišanje pre nego što ona počne da čeka na poziv. Zato monitor pamti koju je mušteriju berberin pozvao (`called`), da li je šišanje završeno (`done`) i da li je mušterija platila (`paid`), a nit čeka na uslovnoj promenljivoj samo ukoliko se to još nije dogodilo.

**Rešenje sa `Signal-and-Continue` disciplinom**

```cpp
#include <thread.h>
#include <monitor.h>
#include <queue>
#define MAX_SEATS 5
#define SHOP_PRICE 400
#define N 10

class BarberShop : SC_Monitor {
    std::queue<int> seats;
    int  called = -1;
    bool done = false;
    bool paid = false;
    int  money = 0;
    cond waitForCustomer;
    cond waitForBarber;
    cond waitForHaircut;
    cond waitForPayment;
public:
    BarberShop() : 
        waitForCustomer(this), 
        waitForBarber(this),
        waitForHaircut(this),
        waitForPayment(this) 
    {
        // empty
    }
    int barber_wait() {
        monitor {
            while (seats.empty())
                waitForCustomer.wait();
            int custId = seats.front();
            seats.pop();
            called = custId;
            waitForBarber.signal();
            return custId;
        }
    }

    int barber_done() {
        monitor {
            done = true;
            waitForHaircut.signal();
            while (! paid) 
                waitForPayment.wait();
            int payment = money;
            called = -1;
            done = false;
            paid = false;
            money = 0;
            return payment;
        }
    }

    bool enter_shop(int id) {
        monitor {
            if (seats.size() >= MAX_SEATS)
                return false;
            seats.push(id);
            waitForCustomer.signal();
            while (called != id)
                waitForBarber.wait();
            return true;
        }
    }

    void exit_shop(int payment) {
        monitor {
            while (! done)
                waitForHaircut.wait();
            paid = true;
            money += payment;
            waitForPayment.signal();
        }
    }
} shop;

void barber() {
    int totalMoney = 0;
    while (true) {
        int custId = shop.barber_wait();
        /* cut hair */
        totalMoney += shop.barber_done();
    }
}

void customer(int id) {
    while (true) {
        if (shop.enter_shop(id))
            shop.exit_shop(SHOP_PRICE);
        usleep(50);
    }
}

int main() {
    Thread tb = createThread(barber);
    Thread tc[N];
    for (int i = 0; i < N; i++) 
        tc[i] = createThread(customer, i);
    join(tb);
    for (int i = 0; i < N; i++) 
        join(tc[i]);
    return 0;
}
```
